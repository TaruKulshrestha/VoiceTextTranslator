This project was my first step into Python programming! in 3rd semester. It combines features like speech-to-text, text-to-speech, and language translation using Python libraries like speech_recognition, pyttsx3, gTTS, and googletrans.

As someone new to Python, I wanted to explore how to:

Recognize speech and convert it into text using a microphone.
Translate text into different languages, such as Hindi, Tamil, Bengali, and Marathi.
Convert text back into speech and play it aloud.
This project helped me understand Python basics, work with external libraries, and build something useful. It's a simple yet exciting journey into programming, and I hope others starting out will find it inspiring! 😊
